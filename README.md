# Clinical Insight Hub (62)

Build a high-end professional portfolio for a Senior Clinical Evaluation Medical Writer. The app should have a sidebar navigation. Sections: 1. Executive Summary (with a professional photo). 2. Clinical Evidence Vault (a searchable grid of oncology research papers). 3. Regulatory Credentials (a clean display for GCP, Pharmacovigilance, and Oncology certifications). 4. Services (CER, PMCF, PSUR writing). Use a clean, clinical aesthetic with a Tailwind 'Slate and Indigo' color theme. Ensure all sections look like high-level medical reports
